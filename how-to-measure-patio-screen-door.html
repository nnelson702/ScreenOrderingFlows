How to Measure for a Replacement Sliding Patio Screen Door

A patio screen door needs more information than width and height. Before ordering, collect the finished door dimensions, frame style, roller type, handle orientation and handle height so the replacement can be manufactured to the configuration you submit.

If you still have the old patio screen door

  1. Lay the door on a flat surface if practical. Avoid measuring a frame that is bowed or twisted.
  2. Measure finished outside width. Measure outside frame edge to outside frame edge and record to the nearest 1/8 inch.
  3. Measure finished outside height. Measure the full outside frame height to the nearest 1/8 inch.
  4. Record the roller type. Match the roller configuration to the options shown in the live ordering tool.
  5. Record handle orientation. Determine whether the handle is on the left or right as configured for the replacement door.
  6. Measure handle height. Measure from the bottom of the door to the handle location using the whole-inch and fraction fields provided by the tool.

If the old door is missing

You will need to determine the finished door size that fits the patio-door screen track. Measure the actual track/opening where the screen door rides, and verify both top and bottom conditions before deciding on a finished door dimension.

Important: Patio-door tracks and roller systems vary. When an original door is missing, do not assume the track opening itself equals the finished replacement-door size. The replacement is built from the specifications you provide.

Choose the correct door frame

The Helpful ACE configurator currently supports Rolled Form Steel, Standard Aluminum and Supreme Aluminum patio-door frame options. These profiles are not interchangeable in every opening, so compare the existing door and available installation space before selecting.

Choose the screen material

The door can use the materials supported by the live ordering tool, including fiberglass, solar-screen choices, SunTex, aluminum, pet-resistant screen and VIMCO 20x30 where available for the selected configuration.

Compare current screen materials.

Final check before ordering

  • Finished outside width and height are correct to the nearest 1/8 inch.
  • Door frame style matches the opening.
  • Roller selection matches the existing system.
  • Handle side is correct.
  • Handle height is measured from the bottom as requested by the tool.
  • Screen material and color are correct.

After payment, the specifications are sent to ScreenFab for manufacturing through Helpful ACE's normal vendor-order process.
