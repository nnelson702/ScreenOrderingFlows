Patio door construction options

The current Helpful ACE ordering program supports the ScreenFab patio-door styles below. Availability and pricing are shown in the live configurator.

Rolled Form Steel

An economical rollformed steel patio screen door option for customers whose opening and hardware configuration match the available steel profile.

Standard Aluminum

An extruded aluminum patio screen door option with a 2-inch-wide frame and approximately 1/2-inch thickness.

Supreme Aluminum

A heavier decorative extruded aluminum door profile. This option can require different installation spacing than the Standard Aluminum configuration.

Rollers and handle details matter

Patio screen doors depend on more than width and height. Roller type, handle orientation and handle height can determine whether a replacement door installs and operates correctly. Our ordering tool collects those details before the quote is submitted so they travel with the manufacturing specifications.

  • Select the roller type available for the chosen door configuration.
  • Choose left or right handle orientation.
  • Enter handle height from the bottom of the door to the nearest supported fraction.
  • Confirm the finished outside width and height before submitting.
Do not guess hardware details. If you still have the old door, use it as a reference for roller and handle placement. Your replacement door is manufactured from the information you provide.
